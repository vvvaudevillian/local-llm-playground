Local LLM Playground

A sandbox for local AI experiments running on Ollama and Python.

This project contains:

  • A working local LLM environment (Ollama + Python)
  • A lightweight Chat UI powered by Gradio
  • Tools, scripts, and demos for experimenting with local models

Getting Started

Clone the repository:

git clone https://github.com/vvvaudevillian/local-llm-playground.git

Run the chat UI:

cd local-llm-playground/local-llm-chat
source ../.venv/bin/activate
python ui.py
