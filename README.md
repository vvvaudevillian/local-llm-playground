# Local LLM Playground

This project is a lightweight scaffold for experimenting with **local LLMs** using:
- Python virtual environments for isolation
- **Ollama** as the local model runtime (http://localhost:11434)
- A simple `chat.py` script that sends prompts to the local model via HTTP
